히어로 테두리 애니메이션 참고 / 적용:
https://reactbits.dev/text-animations/stroke-text
https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/TextAnimations/StrokeText
React Bits Stroke Text의 SVG 글자별 stroke-dashoffset 방식과 기본 stagger를 기반으로
두 줄 히어로에 맞게 수정했고, 반복하지 않고 한 번만 그립니다. sine.inOut은 (1 - cos(PI * progress)) / 2로 계산합니다.
GSAP 대신 브라우저 requestAnimationFrame을 사용하며, 추가 런타임 의존성은 없습니다.
글꼴 설정은 피그마 node 122-767을 따릅니다: Special Gothic Expanded One Regular, 자간 0, 외곽선 1px.

React Bits Lanyard(TS + CSS)를 src/components/Lanyard.tsx로 옮기고 카메라 거리·목줄 굵기·재질을 Contact 배치에 맞게 수정했습니다.
src/assets/lanyard/card.glb는 React Bits의 card.glb에서 로고가 그려진 텍스처 이미지만 1×1 흰색으로 바꾼 파일입니다(모양은 그대로).
src/assets/lanyard/staff-pass-card.png는 위 Contact 피그마(node 178-181 스태프 패스)를 기준으로 만든 카드 앞·뒤 그림입니다.
프로필 이름·이메일을 바꾸면 이 그림도 다시 만들어야 합니다.
카드 윗부분의 슬롯 구멍은 피그마 '패스 구멍'(72×9.6, 둥근 모서리 4.8)을 따라 그렸고, staff-pass-card-cutout.png(검은색=뚫린 부분)로 실제로 뚫습니다.
모델에 있던 작은 동그란 구멍은 Lanyard.tsx에서 같은 재질의 작은 원판으로 막았습니다.
src/assets/lanyard/strap.png는 피그마 목줄 색(#A3A3A3) 단색 이미지입니다.
