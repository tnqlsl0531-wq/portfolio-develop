https://reactbits.dev/text-animations/stroke-text

React Bits Stroke Text의 SVG 글자별 stroke-dashoffset 방식과 기본 stagger를 기반으로
두 줄 히어로에 맞게 수정했고, 반복하지 않고 한 번만 그립니다. sine.inOut은 (1 - cos(PI * progress)) / 2로 계산합니다.

https://reactbits.dev/c/text-animations/shiny-text

글자 기본색(color)은 쓰지 않고 기존 글자 그라데이션 위에 반짝임 띠만 겹쳤습니다. motion 라이브러리 대신 CSS 애니메이션으로 구현해 추가 의존성은 없습니다.
