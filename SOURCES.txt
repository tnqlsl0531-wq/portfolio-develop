로고 마스크는 원본 마스크의 벡터 레이어입니다. SVG 파일 내용은 변경하지 않았습니다.

https://github.com/google/fonts
각 글꼴의 라이선스는 src/assets/fonts에 동봉했습니다.
Noto Sans KR은 @fontsource-variable/noto-sans-kr 5.3.0의 웹용 WOFF2 파일을 사용합니다.

히어로 테두리 애니메이션 참고 / 적용:
https://reactbits.dev/text-animations/stroke-text
https://github.com/DavidHDev/react-bits/tree/main/src/ts-default/TextAnimations/StrokeText
React Bits Stroke Text의 SVG 글자별 stroke-dashoffset 방식과 기본 stagger, repeatDelay를 기반으로
두 줄 히어로에 맞게 수정했습니다. sine.inOut은 (1 - cos(PI * progress)) / 2로 계산합니다.
GSAP 대신 브라우저 requestAnimationFrame을 사용하며, 추가 런타임 의존성은 없습니다.
기존 Special Gothic Expanded One 글꼴에 fontWeight 900 / font-synthesis: weight를 적용했습니다.
